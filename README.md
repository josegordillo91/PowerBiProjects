📊 Practicando análisis de datos con Power BI

Actualmente estoy trabajando en un ejercicio práctico de análisis de datos utilizando Power BI y Excel. El objetivo fue analizar información de ventas de una zapatería a partir de distintos datasets (clientes, pedidos y productos).

Durante la práctica trabajé en:

• Limpieza y preparación de datos

• Modelado de datos y relaciones entre tablas

• Creación de visualizaciones interactivas

• Análisis de ventas por cliente, producto y ubicación

• Uso de mapas para visualizar la distribución geográfica de pedidos

El dashboard permite identificar patrones de compra, clientes con mayor volumen de pedidos y zonas con mayor demanda, lo que podría ayudar a mejorar decisiones comerciales y logísticas.

Herramientas utilizadas:

• Power BI

• Excel

• Modelado de datos

• Data Visualization

Sigo profundizando en análisis de datos y Business Intelligence para transformar datos en información útil para la toma de decisiones.

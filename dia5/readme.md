📊 Proyecto Día 5 | Dashboard en Power BI

Hoy completé un nuevo proyecto enfocado en análisis de datos y visualización con Power BI, donde trabajé sobre un modelo de ventas aplicando buenas prácticas de BI.

🔍 ¿Qué hice en este proyecto?

✔ Construcción de un modelo de datos (tabla de hechos + dimensiones)

✔ Creación de medidas en DAX para análisis de facturación y unidades

✔ Desarrollo de dashboard interactivo con foco en negocio

✔ Uso de segmentadores para análisis dinámico

📈 Insights que pude obtener:

• Comparación de rendimiento entre sucursales

• Identificación de la sucursal con mayor facturación anual

• Análisis de ventas por región y períodos específicos

• Ranking de desempeño por sucursal

🧠 Enfoque aplicado:

No solo me enfoqué en visualizar datos, sino en construir un dashboard que permita responder preguntas de negocio de forma clara y rápida.

🚀 Sigo profundizando en:

Power BI | SQL | Análisis de datos | Modelado de datos
